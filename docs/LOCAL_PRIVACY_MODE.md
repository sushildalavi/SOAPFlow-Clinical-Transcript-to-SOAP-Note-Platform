# Local Privacy Mode

## Default posture

- Keep transcription, generation, and storage local when possible.
- Use local backends such as Ollama or MLX if available.
- Avoid cloud API requirements for the default demo path.

## Suggested local stack

- local transcription if supported by the host
- local LLM backend when available
- local database and vector store

## Notes

- The proof doc and evaluation artifacts should be used to explain the workflow, not to claim clinical safety.
